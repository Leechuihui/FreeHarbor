③ 客户端下载

  • iOS / macOS — Shadowrocket（美区 App Store，付费 ¥18），扫码即加
  • macOS / Windows / Linux 图形界面 — Clash Verge Rev，配置 → 导入
  • 全平台命令行 — sing-box，用本仓库 singbox.json

仓库内已备好 Clash 配置 和 Sing-box 配置，下载后直接导入。
